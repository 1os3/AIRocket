# 严格稳态数据采集加速

## 目标与边界

本方案只接受标准 MRT-LBM 最终严格收敛的黏性流场。势流、预条件和相邻工况结果只能用于初始化或可选快速档，不能直接代替标签。

默认采样 Re 改为 `[100, 500]`：在 `chord=32`、`tau_min=0.52`、`u_lb_max=0.15` 下可准确实现该范围。旧 `[500, 5000]` 的可达上限只有 Re=720，高段会被截断且更容易进入非定常状态。

## 已采用方案

- 连续 3 次检查满足残差阈值才判稳态，降低周期流相位巧合造成的假收敛。
- `conv_tol=1e-4`；需要高精度对照时可改回 `1e-5`。
- 64 个常强度源面元构造无粘不穿透速度场，只作为 LBM 初值，并将速度限制在 `1.5*u_lb`。
- 16K 计划按实际 `u_lb/tau` 与攻角、翼型参数做 Morton 局部排序；每批从近期最近严格稳态样本延续完整分布函数。
- 新旧几何不一致的格点回退到目标工况平衡态，失败样本不进入延续库。
- 压力输出按每个样本的流体域零均值规约，消除初值导致的任意常数偏移。
- 粗细网格步数分别记录为 `coarse_steps/fine_steps`，`steps` 保存真实总步数。

## CPU 固定样本基准

环境：Windows、PyTorch 2.13 CPU、`160x80`、bounce-back、float32、检查间隔 500。墙钟时间包含势流初始化；同一行比较使用同一固定样本。

| 变化 | 旧 | 新 | 加速与误差 |
| --- | ---: | ---: | --- |
| 势流初值，样本 1 | 12500 步 / 40.91 s | 10000 步 / 31.12 s | 1.31x；`ux/uy` 相对差 `1.1e-6/3.5e-5` |
| 势流初值，样本 0 | 23500 步 / 73.37 s | 19500 步 / 63.22 s | 1.16x；`ux/uy` 相对差 `2.7e-6/7.2e-5` |
| `1e-4` 阈值，样本 1 | 10000 步 / 31.12 s | 7000 步 / 22.08 s | 1.41x；`uy` 差 0.028%，压力差 0.107% |
| `1e-4` 阈值，样本 0 | 19500 步 / 63.22 s | 12500 步 / 38.96 s | 1.62x；`uy` 差 0.057%，压力差 0.390% |
| 最近邻完整状态延续 | 23500 步 / 76.23 s | 17500 步 / 52.53 s | 1.45x；`uy` 差 0.016%，压力差 0.122% |
| scale=2 粗细续接 | 7000 步 / 20.60 s | 粗3500+细5500 / 19.01 s | 1.08x；默认关闭 |

势流初值和长尾阈值在两个样本上的实际组合加速约 `1.85~1.88x`。最近邻延续在长序列上还可继续摊薄，单对样本实测再加速 `1.45x`。本机无 CUDA，不能把 CPU 结果外推成 GPU 吞吐承诺。

4 样本端到端测试为 `4/4` 收敛并生成 4 个 LMDB，步数范围 `6000~10000`。无量纲速度场两两 RMS 差为 `0.0266~0.0476`，暂未出现数据过于单一的迹象。

## 已否决或保留为可选

- BGK/TRT：当前低 `tau` 工况在 500~1000 步内出现 NaN，不采用。
- 分布函数块外推：残差快速放大并发散，不采用。
- `gamma=0.6` 预条件：约 1.50x，但 `uy` 与压力分别偏离标准 MRT 约 2.55% 和 4.96%，仅保留配置开关。
- `gamma=0.6 -> 1.0` 两阶段退火：比单独势流初值更慢，不采用。
- Bernoulli 压力初值：没有减少步数，不采用。

## 后续更强路线

1. 在 Linux CUDA 上验证 `torch.compile`、CUDA Graph 和批大小 32/48/64；这是达到高吞吐的首要工程项。
2. 用已生成稳态样本训练低分辨率神经算子，只预测初值，再由标准 MRT 严格收敛校正；这样不会把代理误差写入标签。
3. 若仍需更高 Re 的严格数学稳态，考虑 Newton-Krylov/FAS 多重网格直接求稳态离散方程；显式时间推进无法收敛到物理上不稳定的稳态分支。
