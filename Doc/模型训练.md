# 流场残差 Transformer 与训练系统

## 1. 任务定义

网络不从零预测流场，而是在精确翼型 SDF 与无粘源面元基线之上学习黏性修正。模型输出为：

```text
[(ux-u0x)/u_lb, (uy-u0y)/u_lb, (p-p0)/u_lb²]
```

`p0=0.5*(u_lb²-|u0|²)`，并与 GT 压力一样在流体域采用零均值规约。SDF 使用
`clamp(sdf/chord,-1,1)`；实际 `Re_lattice`、`nu` 与 `u_lb` 作为额外工况条件。

SDF 的原始值由 NACA 折线到每个格子中心的精确最短欧氏距离生成：先按四位数公式
在前后缘余弦加密采样，绕四分之一弦点旋转攻角，再把格子中心换算到弦长归一坐标。
点投影到每条闭合折线段并将投影参数截断到 `[0,1]`，所有线段距离的最小值即距离；
even-odd 射线法判定的翼型内部取负，最后乘弦长恢复格子单位。AABB 只剔除绝不可能
位于多边形内部的点，不近似距离；CPU/CUDA 分块也只影响内存与速度。

默认 `128×256` 网格、255 个折线顶点的 CPU 基准中，20 组翼型优化前后逐点完全一致；
4 线程中位数由 `56.446 ms` 降至 `13.180 ms`（4.28×），14 线程由
`126.639 ms` 降至 `63.289 ms`（2.00×）。

## 2. 网络结构

- Patch Size 为 `8×8`，token 维度 384，默认 `128×256` 网格形成 512 个 token。
- 12 个 Pre-RMSNorm Transformer Block；SDPA 为 6 头非因果全局注意力。
- FFN 为 `384→1536→SwiGLU(768)→384`。
- 24 个子层保存各自原始增量。第 `s` 个子层输入为此前所有增量的静态 Softmax
  加权和，不执行普通 `x+F(x)`。25 行因果 logits 以压缩下三角存储，共 325 个标量，
  全零初始化时每行是历史均匀平均。
- 最终特征经 RMSNorm 后进入三级 `×2` PixelShuffle，空间逐级恢复到原网格。
  每级局部 RMSNorm 只位于细化残差分支，双线性/PixelShuffle 主路径不经过它，
  因此不会形成三个 Norm 串联的唯一梯度通道。

## 3. 精度边界

- 原始输入、Patch Embedding、条件投影与位置编码使用 FP32。
- CUDA Transformer 主干使用 BF16；设备不支持 BF16 时回退 FP16。
- 深度路由 Softmax、完整三级解码器、场重建与全部物理损失使用 FP32。
- FP16 使用 GradScaler，BF16 不使用；CPU 冒烟关闭 autocast，全流程 FP32。

## 4. 物理损失

总目标包括流体域 Huber 监督、一阶梯度监督、不可压散度、稳态 Navier–Stokes
动量残差，以及翼面无滑移、入口速度、出口零梯度、上下周期边界。差分模板不会跨越
固体，压力在损失前固定流体域零均值规约。物理项在训练前 10% 步数内线性升权。

## 5. PowerShell 命令

原始 LMDB 永远只读；第一次训练前先生成独立缓存：

```powershell
.\.venv\Scripts\python.exe train\run.py --mode prepare
.\.venv\Scripts\python.exe train\run.py --mode train
.\.venv\Scripts\python.exe train\run.py --mode eval --checkpoint output\training\best.pt
```

CPU 最小冒烟使用正式 12 层结构，执行完整前后向、单样本过拟合、checkpoint 往返
和预测图渲染：

```powershell
.\.venv\Scripts\python.exe train\run.py --env config\train_smoke.yaml --mode smoke
```

正式训练的可调参数全部位于 `config/default.yaml`；环境差异使用覆盖 YAML，禁止在
实现文件中复制默认值。
