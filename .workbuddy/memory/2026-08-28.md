## 追加：Bouzidi 插值反弹边界（solver.boundary）

- 新增 `solver.boundary: bounce_back|bouzidi`（默认 bouzidi；smoke 用 bounce_back 求快）。
- airfoil 新增 `build_airfoil_geometry` 返回 (mask, sdf)：SDF=点到边界折线最近距离、固体内取负。
- 链路预计算：bmask=流体端邻固节点，q=df/(df−ds) 线性估计。
- **踩坑**：BFL 原式 q≥1/2 分支的 f_ī 记忆项若取上一步 Bouzidi 修正值（递归），与 MRT 形成正反馈，~250 步发散（f64/升 tau 均无效）；改为取碰撞后族群 f_ī* 的变体后稳定。薄翼尖处上游节点不足时回退简单反弹。
- **判据配套修正**：Bouzidi 修稳后 max 范数收敛地板 ~1.3e-5（壁面单点 f32 级残余振荡），改全场 L2 相对变化 ‖Δu‖₂/‖u‖₂：bounce_back 16500 步、bouzidi 13500 步收敛，远场 ux 与 u_lb 一致。conv_tol 语义=L2 相对值（default 1e-7，smoke 1e-5）。

## 关键经验

- LMDB subdir=True 不会自动建目录，需先 mkdir。
- 低 Re（<1000）粘性弛豫慢：chord=32 网格需 ~2 万步收敛；正式配置 chord=128 时需按 GPU 实测调 max_steps。
- .venv 为 torch 2.13.0+cpu（无 CUDA），生产跑需换 CUDA 版 torch；代码 device=auto 已兼容。
